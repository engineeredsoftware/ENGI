# web-search

Family folder for web search providers and orchestrators.

| Nested | Package | Role |
| --- | --- | --- |
| `multi/` | `@bitcode/web-search` | Multi-provider orchestrator (current default) |
| `exa/` | `@bitcode/web-search-exa` | Exa.ai neural search provider |

Prefer importing `@bitcode/web-search-exa` for Exa-only callers.
