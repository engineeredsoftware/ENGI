# @bitcode/generic-artifacts-supabase

**Supabase Storage** `ArtifactStorage` provider base.

```
@bitcode/artifact-generics  ArtifactStorage contract
        ↑
@bitcode/generic-artifacts-supabase   # this package
```

Env: `SUPABASE_URL`, `SUPABASE_ANON_KEY` (or `NEXT_PUBLIC_SUPABASE_ANON_KEY`).
Bucket: `artifacts` (default).
