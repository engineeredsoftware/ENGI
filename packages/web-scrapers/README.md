# web-scrapers

Nested packages for web scraping / crawling providers.

## Hierarchy

```
packages/web-scrapers/
  firecrawl/     # @bitcode/web-scrapers-firecrawl
```

| Path | Package | Role |
| --- | --- | --- |
| `firecrawl/` | `@bitcode/web-scrapers-firecrawl` | Firecrawl scrape/crawl/search client |

BC: `@bitcode/firecrawl` re-exports this package.
Tools: `@bitcode/generic-tools-firecrawl`, `@bitcode/web-search` consume it.
